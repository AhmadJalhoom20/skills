# Agent Skills Collection ⚡

A curated collection of production-grade AI agent skills for modern frontend and fullstack development.

## 📦 Included Skills

### 1. [nextjs-react-clean-code](./nextjs-react-clean-code)
Production-grade skill to refactor messy, AI-generated React & Next.js spaghetti into clean, robust, and maintainable code meeting senior software engineer standards.

- **Stack**: React 19, Next.js 15 (App Router), TypeScript, Tailwind CSS
- **Features**: Architectural decoupling, state hygiene, server/client boundaries, performance optimization.

### 2. [frontend-noslop](./frontend-noslop)
Design & frontend polish skill that eliminates generic "AI slop" UI patterns in favor of intentional, high-taste, and craft-driven interfaces.

- **Focus**: Distinct typography, deliberate spacing, restrained palettes, thoughtful motion, and polished micro-interactions.
- **Includes**: Delivery gates, curated libraries, and slop prevention anti-patterns.

---

## 🚀 How to Use

You can clone this repository or link individual skills into your agent or Claude Code configurations:

```bash
git clone https://github.com/AhmadJalhoom20/skills.git
```

To install any of the skills into your local agent environment:
- Copy the target skill directory to your agent's skills folder (e.g., `~/.gemini/config/skills/` or `.claude/skills/`).
